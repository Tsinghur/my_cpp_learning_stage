# 合并md文档

1. windows

   ```shell
   # Windows-cmd，not shell
   type *.md > 合并文档.md
   ```

2. linux

   ```shell
   # Mac/Linux
   cat *.md > 合并文档.md
   ```


# 超链接

1. **跳转到标题（最常用，不用手动插锚点）**

   - 语法

       ```html
       [点击显示的文字](#目标标题)
       ```
       
   - 示例

       [跳转到标题：合并md文档](#合并md文档)

        > **规则**
        >
        > 标题里**空格变 `-`**，英文自动小写，特殊符号直接去掉

2. **跳转到任意位置（自定义锚点）**

   - 第一步：在目标位置插锚点语句

     ```html
     <a id="自定义标记名"></a>
     ```

   - 第二步：写超链接跳转语句

     ```html
     [跳转到指定位置](#自定义标记名)
     ```

3. **跨md文档跳转**

  1. **基础跨文档跳转（仅打开目标文档）**

     ```html
     [显示文本](目标文档路径)
     ```

  2. **跳转到目标文档的标题位置**

     ```html
     [显示文本](目标文档路径#标题ID)
     ```

     > 目的文档的目的地的锚点设置依旧为
     >
     > ```html
     > <a id="自定义标记名"></a>
     > ```
