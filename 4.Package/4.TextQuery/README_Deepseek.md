# 文本查询程序

文本查询程序的三个迭代版本，逐步引入更现代的 C++ 编程实践。

---

## V1 — 字典/词频统计

最基础的版本：读取文本文件，清洗单词（仅保留字母并转小写），统计词频，输出到文件。

**核心设计：**
- `Dictionary` 类：`read()` 读取文件并统计，`store()` 输出词频文件
- `cleanWord()` 静态方法风格的成员函数，去除非字母字符并转小写

**运行方式：** 硬编码文件路径，直接编译运行即可。

---

## V2 — 单词行级查询

在 V1 词频统计的基础上，增加了**行号追踪**和**按行查询**的能力。查询某个单词时，会显示该单词出现的总次数以及每一处所在的完整行内容。

**相比 V1 的改进：**
- 新增 `vector<string> m_lines` 逐行存储原文，支持按行号回查
- 新增 `map<string, set<int>> m_wordNumbers` 记录每个单词出现过的所有行号（`set` 自动去重排序）
- `query()` 方法：先检查单词是否存在，再输出次数和所有匹配行
- 支持命令行参数：`./text_query_V2 <文件名> <查询词>`
- 增加了文件打开失败的错误处理

**核心设计：**
- `TextQuery` 类承担全部职责：读取、存储、查询
- 使用 `std::getline` 按行读取，`std::istringstream` 按单词解析

---

## V3 — 面向对象重构 + 现代 C++

在 V2 功能基础上进行了全面的架构改进，引入了更多 Modern C++ 惯用法。

**相比 V2 的改进：**

| 方面 | V2 | V3 |
|------|----|----|
| 数据共享 | 查询时复制数据 | `shared_ptr` 共享文件内容和行号集合，避免拷贝 |
| 结果封装 | `query()` 直接输出 | 引入 `QueryResult` 类封装查询结果，输出逻辑分离到 `print()` 函数 |
| 初始化 | `readFile()` 分离的读取步骤 | 构造函数直接完成文件读取（RAII） |
| 交互方式 | 单次命令行查询 | 交互式循环查询，输入 `q` 退出 |
| 单词清洗 | 仅保留字母 | 额外保留连字符 `-`（如 `state-of-the-art`） |
| 现代 C++ | `new`、显式迭代器类型 | `make_shared`、`auto`、`const` 成员函数 |

**架构分层：**

```
TextQuery（构建索引）
    │
    │ query(word)
    ▼
QueryResult（查询结果：单词、次数、行号集、文件内容）
    │
    │ print(ostream&, QueryResult)
    ▼
  输出
```

- `TextQuery`：构造函数接受 `ifstream&`，完成文件读取和索引构建。使用 `shared_ptr<set<int>>` 按需分配每个单词的行号集合。
- `QueryResult`：纯数据类，持有查询词、出现次数、行号集合的 `shared_ptr` 和文件内容的 `shared_ptr`，不拷贝任何大对象。
- `print()`：友元函数，负责格式化输出，与数据分离。

**运行方式：**
```
./text_query_V3 <文件名>
```
进入交互模式后，输入单词查询，输入 `q` 退出。

---

## 演进总结

```
V1:  词频统计         →  map<string, int>
V2:  +行号追踪        →  map<string, set<int>>  + vector<string>
V3:  +智能指针共享     →  shared_ptr + QueryResult 封装 + RAII构造 + 交互式查询
```

三个版本展示了 C++ 从面向过程风格逐步过渡到现代面向对象风格的过程，涵盖了 STL 容器、智能指针、RAII、const 正确性、友元函数等核心概念。
