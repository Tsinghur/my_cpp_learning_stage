# TextQuery —— C++ 文本查询程序（三版演进）

本目录包含同一个文本查询程序的三个版本，展示了从简单词频统计到现代 C++ 面向对象设计的演进过程。

## 目录结构

```
4.TextQuery/
├── V1/text_query_V1.cc   # 词频统计
├── V2/text_query_V2.cc   # 行号追踪 + 单次查询
└── V3/text_query_V3.cc   # 面向对象重构 + 交互式查询
```

## 版本说明

### V1 —— 词频统计

最简实现，读取文本文件，统计每个单词的出现次数，结果写入输出文件。

**核心数据结构：**
```
map<string, int>   单词 → 出现次数
```

**用法：** 硬编码文件路径，直接运行即可，结果写入 `dict2.txt`。

**局限：** 不保留原始行内容，无法定位单词位置；不支持查询。

---

### V2 —— 行号追踪 + 单次查询

在 V1 基础上增加行级索引，支持按单词查询并显示所有匹配行。

**核心数据结构：**
```
vector<string>          每行原文
map<string, set<int>>   单词 → 出现的行号集合
map<string, int>        单词 → 出现次数
```

**用法：**
```bash
./text_query_V2 <文件路径> <查询词>
```

**局限：** 一次运行只能查询一个单词；数据与输出逻辑混合在 `query()` 中。

---

### V3 —— 面向对象重构 + 交互式查询

引入 `QueryResult` 类封装查询结果，使用 `shared_ptr` 共享数据，支持交互式循环查询。

**类设计：**

| 类 | 职责 |
|----|------|
| `TextQuery` | 读取文件、建立索引、执行查询，返回 `QueryResult` |
| `QueryResult` | 封装单次查询结果（单词、次数、行号集合、文件内容） |
| `print()` | 友元函数，负责将 `QueryResult` 输出到流 |

**核心数据结构：**
```
shared_ptr<vector<string>>          文件内容（共享所有权）
map<string, shared_ptr<set<int>>>   单词 → 行号集合（共享所有权）
map<string, int>                    单词 → 出现次数
```

**用法：**
```bash
./text_query_V3 <文件路径>
# 进入交互模式，输入单词查询，输入 q 退出
```

**改进点：**
- 数据与展示分离（`query()` 返回对象，`print()` 负责输出）
- `shared_ptr` 避免文件内容和行号集合的重复拷贝
- 构造函数完成文件读取（RAII 风格）
- `cleanWord()` 额外保留连字符 `-`，支持 `state-of-the-art` 这类复合词
- 支持交互式循环查询

## 核心算法

**单词清洗（`cleanWord`）：** 遍历字符，保留字母（V3 额外保留 `-`），统一转小写，过滤标点和数字。

**索引构建：** 用 `std::getline` 逐行读取，`std::istringstream` 按空白分词，清洗后更新行号集合和词频计数。
